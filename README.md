# RPG Boss Bar 1.10.0

Extensão para Owlbear Rodeo com Boss Bar estilo Souls-like e introdução sincronizada para Mestre e jogadores.

## Recursos
- Boss Bar sincronizada por metadata da sala.
- Introdução de Boss com imagem, nome, subtítulo, duração e fundo.
- Fade-in e fade-out sincronizados.
- Exibição temporária de dano.
- Interface em Português, Inglês, Espanhol e Japonês.
- O idioma é salvo individualmente para cada usuário.
- Boss Bar posicionada mais acima para evitar a área inferior de Assets/controles do Owlbear Rodeo.
- Controles de alteração restritos ao Mestre.
- Sem sistema de cinemática.

## Compatibilidade
- Owlbear Rodeo Extension Manifest v1
- @owlbear-rodeo/sdk 3.1.x

## Validação
- Referências residuais ao build de cinemática removidas.
- Arquivos TypeScript verificados com o parser TypeScript do Node.
- Manifest e package.json validados como JSON.
